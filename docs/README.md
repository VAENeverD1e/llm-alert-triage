# Documentation Assets

This folder contains architectural diagrams, formal proposals, and decision logs.

## Files Overview

- `proposal_condensed.docx`: Condensed thesis proposal or link to original research repository.
- `architecture.png`: Visual diagram depicting the multi-stage triage workflow:
  `Detection -> Fact-Finding Agent -> Verdict Agent -> Discord Notification`.
- `decisions.md`: Scope-cut log and architectural decision records (ADRs).
